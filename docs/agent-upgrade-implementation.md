# 剧情助手、Skill 与工具调用升级

## 当前进度

本次升级按四个阶段推进：助手体验与上下文、内置工具闭环、Skill 管理、远程 MCP 与普通角色聊天工具。桌面与移动端已接入本机连续助手会话、原生工具轮次、可确认的记忆及 Lore 候选、Skill 渐进加载、远程 MCP 授权调用，以及普通角色聊天的逐聊天工具开关。

## 已实现的基础

- Agent 草案使用独立的系统指令。角色设定、persona、画像、Lore、记忆和近期消息作为引用资料放进用户消息，不再保留原先的角色聊天消息角色结构；引用资料不能对 Agent 发出指令。
- 近期消息随实际送入模型的文本提供真实消息 ID。Agent 仅能引用这些 ID；服务端对输出中的 `[source:ID]` 进行白名单校验。
- 记忆与 Lore 候选使用严格校验的 JSON 对象，每项独立携带消息/记忆来源 ID，并在服务端按实际提供过的 ID 过滤。无有效引用时来源数组为空；保存记忆不会再自动附上无关的最近 20 条消息。旧标记文本不再产生可执行候选。
- 新增当前聊天专用的 Agent 历史搜索接口 `GET /api/chats/:id/agent/history-search`，支持现有分页参数。它排除手动移出上下文的消息和已删除聊天；普通消息搜索行为不变。桌面与移动后端采用同一边界。
- Agent 输出中有效的消息引用可在侧栏点击跳转；启用 `tool_calling` 的模型也可通过当前聊天的读取工具检索旧消息。
- 桌面 Prisma 与移动存储分别保存当前聊天的助手会话和逐轮消息。快捷任务作为对话轮次，用户可以输入追问；刷新后读取历史，重复提交同一 `mutationId` 不重复调用模型。
- 会话仅留在本机，不进入聊天归档、备份、恢复点或局域网同步；永久删除聊天和替换数据会移除对应会话。启动时把未完成轮次标记为中断，不自动重放。
- 助手任务可显式停止；隐私锁会中止当前进程的助手模型请求。侧栏提供清空历史；回复草案遇到已有输入时提供追加或替换选择。
- 模型配置增加显式 `tool_calling` 能力。未声明的模型沿用文本助手；声明后，OpenAI-compatible、Anthropic 和 Gemini 使用各自原生工具协议，供应商调用关联信息仅在当前运行内存中保留。Gemini 的原始签名随模型响应回传。
- 桌面和移动端共享参数校验与串行工具循环，接入 `search_history`、`read_messages`、`search_memories` 与 `read_character`。消息工具只能查询当前聊天中仍纳入上下文的消息；记忆工具只返回当前聊天启用的记忆，复用现有关键词/向量召回。角色工具只读取当前聊天绑定角色可访问的提示词及启用的内嵌 Lore；私密内容未解锁时只返回锁定状态。读取有数量与正文长度上限；输出引用只接受实际上下文或工具结果中的消息、记忆 ID。点击记忆引用可按 ID 读取并定位，即使该记忆不在首个分页内。
- 工具任务最多 8 轮模型决策、12 次工具调用。初始上下文、`search_memories` 的向量/重排调用和工具决策链共享一个 `ModelRequest`；每次真实供应商调用分别产生并结算 `ModelUsageAttempt`，调用前重估预算。首轮备用模型必须声明工具能力；含图片的角色聊天还要求视觉能力。已执行工具后禁用重试和供应商切换。达到上限后返回已有文字和明确限制提示。
- 记忆新增候选由桌面/移动后端按持久化的 Agent 条目确认；事务同时写入记忆 revision 和候选应用回执。重复确认返回原记忆，不重复新增；来源消息在执行前重新检查聊天归属和上下文状态。
- 记忆更新、合并和禁用候选仅可指定模型实际收到或通过工具读取的当前聊天记忆 ID。提议保存时绑定每个目标的修订号；预览展示目标正文和版本，确认时重新检查版本、启用状态与来源。合并在一个事务中更新首条记忆、禁用其余目标，并把修订归入 `agent_maintenance` 操作批次。重复确认不重复写入；操作可通过现有记忆面板预览和撤销，并在并发修改时按现有冲突处理。
- 目标修订号取自记忆进入初始上下文或工具返回的时刻；模型运行期间若目标已更新，提议不会被保存为可确认候选。移动存储的操作开始/创建时间使用同一时间戳，保持备份恢复时的精确回放。
- Lore 新增与更新候选由桌面/移动后端确认；更新目标只能是当前上下文或 `read_character` 实际暴露的内嵌条目 ID，更新保留其优先级、触发方式和启用状态。候选绑定角色 ID 和生成时的 `updatedAt`，执行前检查角色、目标条目、版本和来源消息。预览展示旧条目与待保存内容；私密角色需输入密码才能预览旧内容和保存。重复确认不再写入，角色变化返回冲突。
- 记忆/Lore 候选的确认弹窗可编辑标题、正文与关键词；服务端校验并保存实际确认的内容。应用回执绑定最终内容，相同请求可安全重试，不同内容的重复确认返回 409。
- 记忆/Lore 候选应用前先由后端只读预览原建议与编辑后的内容、目标、来源数量、角色版本和影响聊天数；用户再执行确认。编辑内容变化会使旧预览失效；最终写入仍重检来源、角色版本与私密权限。引用的长期记忆若已禁用或删除，预览和确认均返回冲突。
- 助手运行通过现有 WebSocket 发出按 `runId`、递增 `seq` 排序的上下文读取、模型决策、工具开始/完成和终态事件；事件不含工具参数或结果正文，仅在进程内短时保留。客户端断线重连可按序号回放，刷新时读取当前会话的 `activeRunId` 后接回同一任务；完成后以本机会话读取最终答复。执行步骤可折叠，锁定时关闭连接并清理事件缓存。
- `GET /api/chats/:id/agent/runs/:runId` 核验该运行属于当前聊天，返回持久化任务状态、完成时间与当前进程已知的最后事件序号，不返回正文。WebSocket 订阅允许在任务提交前建立，因此只先核验聊天有效；事件缓存过期或后端重启后仍可查询最终状态。
- 摘要、建议、回复草案、记忆/Lore 候选与两类检查各有默认温度和输出长度；侧栏可按本次任务调整。后端严格校验参数，并以所选模型实际输出上限为准。任务参数写入本机 `AgentEntry.generation`，同一 `mutationId` 携带不同参数会返回冲突；它不进入备份或同步。新增迁移 `20260923030000_agent_generation`。
- 内置四种 Skill：剧情连续性、记忆整理、角色一致性和回复创作。可导入单个 `SKILL.md` 或 ZIP；导入先预览名称、描述、参考文件与兼容性限制，同名替换绑定版本并重新禁用。导入包默认禁用，可分别启用给剧情助手或指定聊天。ZIP 对路径、符号链接、文件数及解压大小设限；脚本和依赖只标为不兼容，不执行。
- 剧情助手 Prompt 仅提供已启用 Skill 的简短目录；模型调用 `load_skill` 后才读取正文或包内文本参考文件。Skill 内容不能扩大工具权限。Skill 包及启用状态在桌面 Prisma `SkillPackage` 和移动本机记录保存；不进入备份、归档、恢复点或局域网同步。桌面迁移为 `20260923040000_skill_packages`。
- MCP 连接配置使用本机记录；Bearer Token 借用 AES-256-GCM 本地密钥保管，不返回前端，也不进入备份/同步。首次只支持 Streamable HTTP；官方 SDK 显式协商 2026-07-28，必要时回退到 2025-11-25。公网需 HTTPS，局域网和 loopback 需显式允许；DNS 解析时校验并固定地址，拒绝重定向、凭据 URL、云元数据地址与超限响应。连接检查发现最多 100 个工具；工具定义摘要变化会撤销对应启用状态。启用后的工具可加入模型可调用列表，调用前校验参数和定义摘要，并显示服务、工具和将发送的参数以逐次授权；仅用户确认过的读取工具可在当前进程会话复用授权。结果不明时停止，不自动重放。桌面迁移为 `20260923050000_mcp_connections`。
- 普通角色聊天默认关闭工具，在聊天设定中按聊天选择本机读取、Skill 加载与已启用的 MCP 工具；选择只保存在本设备浏览器，不进入备份或同步。角色始终使用聊天模块模型；启用工具且模型显式具备 `tool_calling` 时进入同一 8 轮/12 次上限的执行核心。每次模型决策产生独立 attempt，最终回复仍作为普通角色消息保存；工具步骤单独折叠显示。没有启用工具时仍走原流式聊天链路。`load_skill` 在角色聊天中只读取该聊天启用的 Skill，不能借用剧情助手的全局启用状态。
- Skill 与 MCP 的本机管理入口位于“设置 → Skill 与 MCP”，可导入、查看和启用 Skill，或添加、检查、编辑、启停与删除 MCP 服务器并逐项启用发现的工具。剧情助手提供入口链接；聊天设定中的角色工具按本机读取、Skill 和 MCP 分组，只保留当前聊天的选择。MCP 管理交互参考 Codex 的服务器列表和单工具启用方式，协议与鉴权范围仍按本项目既定边界实现。
- 长期记忆 `index-summary` 静态路由须先于 `:memoryId` 动态路由注册；桌面与移动端回归覆盖。否则打开聊天历史时，Express 会把 `index-summary` 当作记忆 ID 并返回 404。

## 后续强化

3. 扩充模拟 MCP 的端到端验收，覆盖工具授权拒绝、写入结果未知、断线重连和隐私锁；继续检查外部工具定义变化的竞争场景。

模型输出的来源 ID 经过实际上下文/工具结果白名单校验，但不能仅凭 ID 校验证据是否真正支持某项结论；后续结构化结论需逐项绑定实际工具结果。记忆合并当前将首个目标作为保留项，其余目标禁用；预览展示目标正文和版本。
