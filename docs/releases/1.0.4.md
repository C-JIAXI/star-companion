# 星伴 1.0.4 更新说明

这次更新让长剧情聊天更容易回顾和整理，也改进了聊天工作区的操作体验。

## 新功能

- **剧情助手可以继续追问。** 它能查找当前聊天中较早的消息、读取长期记忆，并在回答中标出依据。记忆和角色设定的修改会先展示候选内容，由你确认后保存。
- **可按需联网。** 为模型开启联网工具后，可以搜索网页和读取公开页面。外部调用会先展示将发送的内容，等待你的授权。
- **Skill 与 MCP 管理。** 可以管理剧情助手使用的任务方法和外部工具，并为具体聊天选择允许角色使用的工具。角色工具默认关闭。
- **模型参数按模型保存。** 在聊天中切换模型时，可以分别调整生成参数。

## 体验改进

- 聊天工作区、快捷指令和长聊天滚动更顺手，切换工具时会保留正在编辑的内容。
- 修复了记忆概况接口异常、Windows 启动脚本误判启动状态，以及“联网、Skill 与 MCP”设置页面板高度异常。
- 聊天侧边工具使用始终可见的细线滚动指示，并为按钮和卡片留出间距。

## 使用提醒

- 升级前建议保留一份本地备份。
- 联网和外部工具需要自行配置与开启；密钥只保存在本机，不进入聊天备份。
- Windows 安装包没有正式签名；Android APK 使用调试签名。Android 旧包签名不同时可能无法直接覆盖安装，请先备份聊天数据。

## 下载

- `Star-Companion-Setup-1.0.4-win-x64.exe`：Windows x64 未签名安装包。
- `Star-Companion-1.0.4-android-debug.apk`：Android 调试签名安装包。
- `Star-Companion-1.0.4-preview-SHA256SUMS.txt`：上述两个安装包的 SHA-256 校验值。

本测试版不提供正式签名安装包或稳定自动更新。
