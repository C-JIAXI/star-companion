# Star Companion 1.0.3 — 测试预发布 / Test prerelease

本版本暂不配置正式签名：Windows 安装包没有 Authenticode 签名，Android APK 使用开发调试签名。仅供自愿测试，不作为正式签名或稳定自动更新发布；不上传 `latest.yml` 或稳定更新清单。

This is a test prerelease: the Windows installer is unsigned, and the Android APK uses a development debug key. It is not a signed production release or a stable automatic update.

## 更新 / Highlights

- 完整本机聊天草稿：按聊天保存文字与图片顺序、失败重试、版本冲突选择、待发送快照、发送回执去重及重启后的手动恢复。
- 应用锁取消读图、上传及保存，解锁不会继续旧任务；旧浏览器草稿和队列仅在明确确认后迁移。
- 备份与局域网同步先预检再执行，冲突显式处理，危险写入前自动建立恢复点；补齐大数据分页和恢复验证。
- 全局外观、阅读舒适度与无障碍设置，首次使用引导、模型诊断、存储空间与数据健康中心。
- 安全图片附件、角色创作工坊、模型调用可靠性与预算、可审计记忆历史。
- 修复 Windows 干净检出将 SQL 转为 CRLF 导致迁移校验和漂移的 CI 问题，并加入真实 Git 检出回归测试；CI 显式安装 E2E 所需 Chromium。

## 升级提醒 / Upgrade notes

- **升级前先导出并保留备份。** Android 调试签名可能与旧安装包不同，系统可能拒绝覆盖安装；不要在没有已验证备份时卸载旧应用。
- Windows 可能显示未签名发布者或 SmartScreen 提醒；仅在确认来源和 SHA-256 后自行决定是否测试。
- 应用版本 `1.0.3`，Android versionCode `1000003`。schemaVersion 1 备份继续兼容；数据库包含新的草稿与待发送快照迁移。
- 草稿和待发送快照仅在本机保存，不进入备份、恢复点、聊天归档或局域网同步。草稿图片按原上传时间 24 小时过期，失效后需重新选择。
- 只有后端已确认保存的修改保证持久化；重启后未提交的快照只供手动恢复，不会自动调用模型。
- 产品仍是单用户、单角色聊天及角色内嵌 loreEntries；API Key 不进入前端或迁移载荷。

## 验证 / Validation

功能源码的前一轮完整验收结果见 [草稿实现与验收](../chat-drafts-implementation.md)。本次发布还需通过版本一致性、Windows 干净检出回归、云端 CI、当前版本安装包构建和独立临时数据目录的桌面启动验证；具体最终结果与 SHA-256 随 GitHub Release 公布。
